Pinned models

        
A pin sends one model to one host and ignores the sort above. If that host can't serve the request, it fails instead of moving to another host.

        
Before you pin: Koharu's in-app agent sends tools with each request. If the pinned host doesn't support tools, every agent request fails with a 404 (the proxy explains why). Don't pin a host without tools support if you use the agent.
